# 云展馆章节封面 · 生图提示词

> 配套规范：[云展馆核心视觉元素设计规范](../../云展馆核心视觉元素设计规范.md)  
> 适用元素：D1 章节封面（3:2 母版，1500 × 1000px）  
> 说明：以下是封面生成的方向库；当前 `covers/` 下的三张源图以实际交付为准，提示词不保证与成图逐像素一致。

## 1. 使用说明

- 目标不是“生成一张好看的图”，而是生成**可同时用于卡片缩略图与章节 hero 的 3:2 母版**。
- 所有提示词都必须满足：
  - 画面内**不出现任何文字、书法、印章、Logo、水印、边框**。
  - 主体位于画面**中部偏上**，左侧留出负空间。
  - 画面**底部 40% 保持低细节、偏暗**，供白色章节标题叠加。
  - 色调限定在漆红、赭石、暖金、宣纸米白，不使用蓝紫与霓虹色。
- 生成后必须按第 6 节做裁切、压缩与验收，不能直接使用原图。

## 5. 生成参数

| 项 | 建议 |
| --- | --- |
| 画面比例 | 3:2（横构图） |
| 生成尺寸 | 2400 × 1600px；最低 1536 × 1024px |
| 交付尺寸 | 1500 × 1000px，JPG，sRGB |
| 体积 | 单张 ≤ 250KB |
| Midjourney | `--ar 3:2 --style raw`，可加 `--stylize 150` |
| SDXL | 1536 × 1024，CFG 5–7，Steps 30–40，DPM++ 2M Karras |
| 即梦 / 文心一格 | 比例 3:2，精细度最高，关闭“自动添加文字” |
| 批量一致性 | 固定种子或固定风格参考图，只替换主体描述 |

## 6. 后处理与验收

1. **去水印/去边**：若生成工具在右下角加水印，按 3:2 从左上裁切到 `2100 × 1400`，再缩放到 `1500 × 1000`。
2. **压缩**：JPG 质量 76–80，目标 ≤250KB；纹理较多的画面可降到 68–72。
3. **底部压暗**：检查底部 40% 是否足够暗；不足时由前端加 `.hero-mask`，不要直接把文字烘焙进图。
4. **卡片裁切**：按 170 × 130rpx 居中裁切预览，主体必须完整。
5. **Hero 裁切**：按 686 × 420rpx 居中裁切预览，标题区不得压住主体面部/器物关键纹样。
6. **文字检查**：确认画面内没有生成任何伪汉字、印章或签名。
7. **文化校验**：AI 生成的器物形制、纹饰可能与真实文物不符，正式发布前必须由内容人员核对或替换为有授权的馆藏照片。

## 8. 一致性控制

- 三张封面必须共用同一套色调：深漆红、赭石、暖金、宣纸米白。
- 光线方向统一为左上或右上侧光，避免一张顺光、一张逆光。
- 背景材质统一为炭灰亚麻、深色石材、宣纸三类，不混入白色影棚背景。
- 摄影与线稿风格**不要混用**；本次三张为摄影概念稿，若最终采用线稿风格，应整套替换。
- 统一保留胶片颗粒与低饱和，不使用强 HDR、锐化过度或高饱和滤镜。
