# 蜀漆云馆小程序 · 云展馆核心视觉元素设计规范

| 项 | 内容 |
| --- | --- |
| 文档版本 | v1.0 |
| 更新日期 | 2026-11-18 |
| 适用范围 | `fronted/漆器云馆` 云展馆模块 |
| 读者 | 视觉设计、前端开发、内容运营、验收人员 |
| 设计基线 | 750rpx 宽，1rpx = 1/750 屏宽；Figma 主画板 750 × 1624 |
| 关联实现 | `pages/exhibition/exhibition.vue`、`pages/chapter/chapter.vue`、`uni.scss` |

本文档只覆盖三个核心视觉元素：

- **D1 章节封面**：内容素材，同时服务于列表卡片与章节页 hero。
- **D2 云展馆列表卡片**：云展馆页的章节入口。
- **D3 章节页 hero 通栏**：章节详情页首屏主视觉。

## 2. 全局视觉规范

### 2.1 画布、栅格与安全区

| 项 | 规范 |
| --- | --- |
| 设计画板 | 750 × 1624（iPhone X 比例）；兼容画板 750 × 1334 |
| 开发基准 | uni-app / 微信小程序 `rpx`，750rpx = 屏幕宽度 |
| 页面左右边距 | 32rpx（内容宽 686rpx） |
| 卡片内边距 | 22rpx |
| 栅格 | 以 8rpx 为基础步进；常用间距 8 / 12 / 16 / 20 / 24 / 26 / 32 / 40 / 44 / 48 / 56 / 60rpx |
| 顶部安全区 | 使用微信原生导航栏，hero 不侵入状态栏 |
| 底部安全区 | 固定底栏使用 `env(safe-area-inset-bottom)` |
| 宽屏上限 | uni-app 的 rpx 默认最大适配宽度为 960px；≥768px 时内容区限宽 750px 居中 |

换算规则：

```
设计稿 750px 宽：1px = 1rpx
设计稿 375pt 宽：1pt = 2rpx
开发样式优先写 rpx，仅 1px 发丝线、阴影模糊值可使用 px
```

### 2.2 色彩体系

主色来自 `uni.scss`，禁止在页面内新增近似色。

| Token | 色值 | 角色 | 使用规则 |
| --- | --- | --- | --- |
| `$paper` | `#F6F1E8` | 页面底色（宣纸） | 页面背景、进度条容器 |
| `$paper2` | `#FFFDF8` | 卡片底色（暖白） | 卡片、弹层、底部栏 |
| `$ink` | `#28231F` | 主标题 | 浅色底主标题；对比度 15.30:1 |
| `$muted` | `#81776D` | 次级文字 | 仅用于 ≥24rpx 的非关键文字；浅底对比度 4.31:1，小字不达标 |
| `$muted-strong` | `#6B6259` | 小字号辅助文字（建议新增） | 18–22rpx 辅助文字；对比度 5.87:1（paper2）/ 5.31:1（paper） |
| `$red` | `#762D25` | 漆红主色 | 主按钮、激活态、术语、强调标题；白字对比度 9.67:1 |
| `$red2` | `#9C4939` | 漆红辅助 | 进度条、焦点描边、高亮边框 |
| `$gold` | `#B58A4A` | 金棕装饰 | 仅分隔线、装饰线、深色底文字；浅底对比度 2.79:1，禁止用作正文 |
| `$gold-text` | `#8D6A35` | 浅底金色文字（建议新增） | paper2 底对比度 4.87:1，可用于 ≥20rpx 文字；`$paper` 底对比度 4.40:1，仅限 ≥24rpx 非关键文字 |
| `$line` | `#E6DCCD` | 分隔线 | 1rpx 边框、卡片描边 |
| `$green` | `#5F765E` | 已完成 | 完成标签、完成态图标；对比度 4.87:1 |
| `$dark-1` | `#351B1B` | 深漆底 | hero 渐变终点、深色卡片 |
| `$dark-2` | `#7E352D` | 漆红中间调 | hero 渐变中间色 |
| `$dark-3` | `#A75C42` | 漆红高光 | hero 渐变起点、封面暖色高光 |
| `$overlay` | `#1C1411` | 图片遮罩 | hero 文字保护层，透明度 8%–78% |

语义色使用约束：

- **漆红**只表达“可操作 / 当前 / 重点”，同一屏最多出现 2 处高饱和漆红。
- **金棕**只做装饰与元信息，不承担正文阅读。
- **绿色**只表达完成，不用作普通成功提示以外的装饰。
- 不使用蓝色、紫色、荧光色；不使用纯黑 `#000` 与纯白 `#FFF` 作为大面积底色。

### 2.3 字体层级

字体栈：

```css
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC", "Source Han Sans SC",
             "Microsoft YaHei", sans-serif;
/* 数字、英文眉题、章节号使用衬线字体做品牌对比 */
font-family: Georgia, "Times New Roman", serif;
```

| 层级 | 字号 | 字重 | 行高 | 字距 | 用途 |
| --- | --- | --- | --- | --- | --- |
| Display | 60rpx（30pt） | 500 | 1.2 | 10rpx | 章节页 hero 主标题 |
| H1 | 40rpx（20pt） | 500 | 1.3 | 0 | 弹层标题、页面大标题 |
| H2 | 36rpx（18pt） | 600 | 1.4 | 0 | 节点标题、区块标题 |
| Card Title | 30rpx（15pt） | 600 | 1.4 | 0 | 云展馆卡片标题 |
| Body | 26rpx（13pt） | 400 | 2.0 | 0 | 正文、摘要 |
| Secondary | 22rpx（11pt） | 400 | 1.6 | 0 | 卡片副标题、辅助说明 |
| Caption | 18–20rpx（9–10pt） | 400 | 1.5 | 0 | 标签、来源、时间 |
| Overline | 16rpx（8pt） | 500 | 1.4 | 4rpx | 英文眉题、品牌行 |
| Number | 40–120rpx | 400 | 1.0 | 2–4rpx | 章节号、统计数字（Georgia） |

排版规则：

- 正文与可点击文字不低于 24rpx；纯辅助信息不低于 18rpx。
- 中文标题不使用全大写英文；英文眉题统一大写并加 4rpx 字距。
- 标题最多 2 行；副标题最多 2 行；列表卡片副标题最多 1 行。
- 超出时使用 `overflow: hidden; text-overflow: ellipsis;`，多行使用 `-webkit-line-clamp`。
- 数字使用 `font-variant-numeric: tabular-nums`，避免进度数字跳动。

### 2.4 质感表现

| 项 | 规范 |
| --- | --- |
| 纸张感 | 页面使用 `$paper` 纯色；可叠加 ≤3% 透明度的细颗粒，禁止在正文后方使用明显纹理 |
| 漆面感 | 深色区域使用 `linear-gradient(135deg, #3B2924, #754337)` 或 `radial-gradient(ellipse at 75% 28%, #A75C42 0%, #7E352D 39%, #351B1B 100%)` |
| 圆角 | 小图 12–14rpx；卡片 18–20rpx；hero/大卡 22–24rpx；按钮/胶囊 40–56rpx |
| 描边 | 统一 1rpx `$line`；高亮态使用 `$red2` + 4rpx 外发光 |
| 阴影 | 默认无阴影；仅“当前/高亮”卡片使用 `0 0 0 4rpx rgba(156, 73, 57, .18)`，禁止大面积投影 |
| 图片调性 | 暖色、低饱和、偏赭石/漆红；避免冷色滤镜、过曝、纯白背景 |
| 图片文字 | 封面禁止烘焙文字、Logo、边框、水印；标题一律由前端排版 |

### 2.5 品牌一致性要求

- 三元素必须使用同一套色板与圆角体系，禁止单独发明新色。
- 章节封面统一暖色调；同一章节在卡片与 hero 中使用同一张封面。
- 英文眉题统一为 `SHU QI YUN GUAN · DIGITAL EXHIBITION` 或内容主题英文短句，全大写、4rpx 字距。
- 漆红只用于“当前章节、主操作、已完成/进行中”等有语义的位置。
- 所有空状态、加载态、错误态必须使用同一套纸张色与漆红渐变，不允许出现系统默认灰。

## 3. D1 章节封面

### 3.1 标准尺寸与适配场景

| 场景 | 展示尺寸（rpx） | 展示比例 | 裁切方式 | 说明 |
| --- | --- | --- | --- | --- |
| 云展馆列表卡片缩略图 | 170 × 130 | 17:13 ≈ 1.31 | `aspectFill` 居中裁切 | 主体必须在中心安全区 |
| 章节页 hero 背景 | 686 × 420–520 | 1.63–1.32 | `aspectFill` 居中裁切 | 底部 40% 需要低细节、偏暗 |

### 3.2 生产尺寸与格式

| 项 | 要求 |
| --- | --- |
| 母版尺寸 | 1500 × 1000px（3:2），sRGB |
| 母版格式 | JPG，质量 80，单张 ≤ 250KB |
| 可选格式 | WebP，质量 75，单张 ≤ 150KB（需确认目标基础库支持） |
| 导出倍率 | @2x 1000 × 667；@3x 1500 × 1000 |
| 最小源图 | 卡片场景不低于 1000 × 667px；hero 场景不低于 1500 × 1000px；禁止从小图放大 |
| 透明通道 | 不使用；封面为满幅照片/插画 |
| 色彩配置 | sRGB IEC61966-2.1，禁止 CMYK / P3 直接导出 |

裁切规则：

- 3:2 母版同时服务 17:13 卡片与 1.63:1 hero：卡片左右裁切、hero 上下裁切。
- **中心安全区**：画面中心 70% 区域（左右各留 15%，上下各留 15%）必须包含主体与关键信息。
- **hero 文字区**：画面底部 40% 保持低对比、低细节、偏暗，避免与白色标题冲突。
- 主体建议位于画面中部偏上；避免把人物面部、器物口沿等关键细节放在边缘 12% 区域。

### 3.3 内容布局与视觉风格

| 层级 | 内容 | 要求 |
| --- | --- | --- |
| P0 | 器物主体 / 场景主视觉 | 占画面 40%–70%，焦点清晰 |
| P1 | 环境与材质 | 漆面反光、木胎、纹饰等，服务氛围不抢主体 |
| P2 | 背景留白 | 为标题、遮罩、裁切留出空间 |
| 禁止 | 文字、Logo、边框、水印、拼图式多图 | 一律由前端排版与叠加 |

视觉风格：

- 色调：宣纸暖白、漆红、赭石、金棕；避免蓝紫、霓虹、冷白。
- 光比：柔和侧光，避免死黑与高光溢出；漆面反光可保留但不过曝。
- 质感：真实器物优先；插画需保持纸质纹理与低饱和，不使用 3D 塑料质感。
- 统一性：同一章节的卡片与 hero 必须使用同一张封面，不得分别选图。

### 3.4 缺省封面（无图兜底）

无封面时使用 CSS 渐变，不额外上传图片：

```css
background: radial-gradient(ellipse at 75% 28%, #A75C42 0%, #7E352D 39%, #351B1B 100%);
/* 中央叠加章节号 */
font-family: Georgia, serif;
font-size: 120rpx;
color: rgba(232, 201, 154, .5);
```

### 3.5 质量验收

- 100% 缩放查看无锯齿、无过度锐化、无明显 JPEG 色块。
- 卡片裁切后主体完整，hero 裁切后标题区不压主体面部/器物关键纹样。
- 10 张章节封面并排时色温、对比度、饱和度一致，不出现一张过亮或过冷。

## 4. D2 云展馆列表卡片

### 4.1 标准尺寸与结构

| 项 | 规范 |
| --- | --- |
| 卡片宽度 | 686rpx（页面左右各 32rpx） |
| 卡片最小高度 | 176rpx（含 1rpx 描边） |
| 卡片内边距 | 22rpx |
| 卡片圆角 | 20rpx |
| 卡片背景 | `$paper2` |
| 卡片描边 | 1rpx `$line` |
| 卡片间距 | 26rpx |
| 封面尺寸 | 170 × 130rpx，圆角 14rpx，`flex-shrink: 0` |
| 封面与文字间距 | 18rpx |
| 标题 | 30rpx / 600，最多 2 行 |
| 副标题 | 22rpx / 400，单行省略 |
| 标签 | 18rpx，内边距 2rpx 14rpx，圆角 20rpx |
| 右侧箭头 | 34rpx，颜色 `#A58B6E` |

结构线框：

```
┌─────────────────────────────────────────────┐ 686rpx
│ 22 ┌──────────┐ 18 ┌──────────────────┐ 18 │
│    │          │    │ [序章] [已完成]   │    │
│    │  D1 封面 │    │ 第二章：百工成器  │  › │
│    │ 170×130  │    │ 摘要文字单行省略… │    │
│    │          │    └──────────────────┘    │
│ 22 └──────────┘                             │
└─────────────────────────────────────────────┘
```

### 4.2 内容布局与信息优先级

| 优先级 | 信息 | 规则 |
| --- | --- | --- |
| P0 | 封面 + 章节标题 | 封面必须存在或使用渐变兜底；标题最多 2 行 |
| P1 | 章节类型标签 | 序章显示“序章”；正章显示“第 N 章”，N 只统计正章 |
| P2 | 状态标签 | 已完成（绿） / 读到此章（金） / 未开始（不显示） |
| P3 | 摘要或副标题 | 优先 `summary`，为空时用 `subtitle`，再为空显示“进入章节开始阅读” |
| P4 | 右侧箭头 | 纯 affordance，不承载信息 |

布局规则：

- 标签行始终在标题上方，类型标签在前、状态标签在后，间距 10rpx，下间距 8rpx。
- 标题与副标题左对齐；副标题单行省略，不允许换行挤压卡片高度。
- 封面与文字垂直居中；文字区 `flex: 1`，右侧箭头固定。
- 卡片高度随标题行数变化，但最小高度 176rpx；标题从 1 行变 2 行时允许高度增加，不允许文字溢出封面。
- 同一列表中只允许一张“高亮/继续阅读”卡片。

### 4.3 状态规范

| 状态 | 触发条件 | 视觉表现 |
| --- | --- | --- |
| 默认 | 普通章节 | 背景 `$paper2`，1rpx `$line` 描边 |
| 按压 | 手指按下（`hover-class`） | 背景变为 `#F3ECE1`，整体 `scale(.99)`，120ms ease-out |
| 高亮/继续 | 上次阅读章节 | 描边 `$red2` + 外圈 `0 0 0 4rpx rgba(156,73,57,.18)` |
| 已完成 | `completed = true` | 绿色“✓ 已完成”标签；封面可降低 8% 饱和度，不做蒙层 |
| 读到此章 | 有 `lastReadTime` 且未完成 | 金棕色“读到此章”标签 |
| 图片失败 | `coverUrl` 为空或加载失败 | 使用 D1 缺省渐变 + 章节号 |
| 加载中 | 列表请求中 | 686 × 176rpx 骨架卡，底色 `#EEE6DA`，高光 `#F7F1E7`，圆角 20rpx |
| 空列表 | 无已发布章节 | 居中空状态，文案“暂无已发布章节，请先在后台发布内容” |

交互要求：

- 使用 `hover-class`，不使用 CSS `:hover`；按压态不改变布局尺寸。
- 按压开始时间 20ms，离开保留 70ms；过渡 120ms。
- 点击整张卡片进入章节；封面、标题、箭头不单独设置点击区域。
- 状态不能只靠颜色区分，必须同时有文字标签或图标。

### 4.4 文案规则

| 字段 | 规则 | 示例 |
| --- | --- | --- |
| 章节类型 | 序章 / 第 N 章 | `序章`、`第2章` |
| 标题 | 不超过 2 行，建议 8–16 个汉字 | `第二章：百工成器` |
| 副标题 | 单行，不超过 28 个汉字 | `从制胎到髹饰的完整工序` |
| 摘要 | 单行省略，不出现“……”以外的标点堆叠 | `漆从蜀地来，器物见匠心` |
| 状态 | 固定文案 | `✓ 已完成`、`读到此章` |

## 5. D3 章节页 hero 通栏

### 5.1 标准尺寸与位置

| 项 | 规范 |
| --- | --- |
| 宽度 | 686rpx（左右各 32rpx，内容区通栏） |
| 高度 | 最小 420rpx；封面信息量大会增至 520rpx |
| 推荐比例 | 686:420 ≈ 1.63:1（约 16:10） |
| 圆角 | 24rpx |
| 外边距 | 上 8rpx，左右 32rpx，下 0 |
| 内容内边距 | 左右 44rpx，底部 44rpx |
| 顶部前置 | 阅读进度条（高 6rpx，容器 padding 16rpx 34rpx 12rpx） |
| 层级 | 封面图 → 遮罩 → 装饰线 → 文案 |

尺寸换算：

- 375pt 屏幕：343 × 210px；@3x 约 1029 × 630px。
- 1500 × 1000px 的 3:2 封面在 hero 中按 `aspectFill` 居中裁切，底部文案区不会压到主体。

### 5.2 图层与内容布局

```
┌───────────────────────────────────────┐ 686rpx
│ ① 封面图 aspectFill                   │
│ ② 遮罩：上 8% → 中 28% → 下 78%       │
│                                       │
│                                       │
│  SHU QI YUN GUAN · DIGITAL EXHIBITION │  ← 16rpx，字距 4
│  CHAPTER 02                           │  ← 22rpx，Georgia，字距 4
│  百 工 成 器                           │  ← 60rpx，字距 10
│  从制胎到髹饰的完整工序                 │  ← 24rpx，最多 2 行
└───────────────────────────────────────┘
  44rpx 内边距                     44rpx
```

图层要求：

1. **封面图**：绝对定位铺满，`width/height: 100%`，`mode="aspectFill"`，不做缩放动画。
2. **遮罩（必须新增）**：保护白色文字，底部必须达到 78% 不透明度：

```css
.hero-mask {
  position: absolute;
  top: 0; right: 0; bottom: 0; left: 0;
  background: linear-gradient(
    180deg,
    rgba(28, 20, 17, .08) 0%,
    rgba(28, 20, 17, .28) 45%,
    rgba(28, 20, 17, .78) 100%
  );
  pointer-events: none;
}
```

3. **装饰线（可选）**：标题上方 1rpx 金色短线，宽 56rpx，颜色 `rgba(232,201,154,.55)`，与眉题间距 16rpx。
4. **文案块**：绝对定位 `left/right/bottom: 44rpx`，`z-index` 高于遮罩。

### 5.3 内容优先级与排版规则

| 优先级 | 内容 | 规则 |
| --- | --- | --- |
| P0 | 章节标题 | 60rpx / 500 / 字距 10；最多 2 行 |
| P1 | 章节号 | `CHAPTER 02` + 章节类型；22rpx Georgia，字距 4 |
| P2 | 副标题/摘要 | 24rpx，最多 2 行；优先 `subtitle`，为空用 `summary` |
| P3 | 英文眉题 | 16rpx / 字距 4；纯装饰，可隐藏 |
| P4 | 装饰线 | 可隐藏，不影响信息 |

标题自适应：

- 标题 ≤ 10 个汉字：60rpx / 字距 10。
- 标题 11–16 个汉字：52rpx / 字距 6，最多 2 行。
- 标题 > 16 个汉字：48rpx / 字距 4，最多 2 行，超出省略。
- 不允许标题压到顶部安全区或超出 hero；标题增长时优先增加 hero 高度到 520rpx。
- 当前实现为固定 60rpx，需按上述规则补充标题长度判断与 `hero` 高度自适应。

文案为空时：

- 无副标题且无摘要：隐藏副标题行，标题下移 0。
- 无封面：使用 D1 缺省渐变，中央显示章节号，文案保持不变。

### 5.4 状态规范

| 状态 | 视觉 |
| --- | --- |
| 默认 | 封面 + 遮罩 + 白色文案 |
| 加载中 | 使用 `$dark-1 → $dark-2` 渐变占位，不显示转圈；文案骨架条 40% 透明度 |
| 图片失败 | 与缺省封面一致，显示章节号 |
| 可点击（如后续支持查看大图） | 增加 `hero-pressed`：遮罩整体加深 6%，120ms |
| 不可点击 | 不添加按压态，不显示箭头/提示 |

滚动与动效：

- hero 随页面滚动，不做吸顶、不做视差。
- 首次加载允许 1.00 → 1.02 的 300ms 轻微缩放，禁止循环动画。
- 节点导航吸顶时不得覆盖 hero 文案；hero 与导航之间保留 8rpx 间距。

## 6. 交互适配要求

### 6.1 Hover / 按压态

微信小程序没有桌面端 hover，统一使用 `hover-class` 表达触摸反馈。

| 元素 | hover-class | 视觉变化 | 时长 |
| --- | --- | --- | --- |
| D2 卡片 | `card-pressed` | 背景 `#F3ECE1`，`scale(.99)` | 120ms ease-out |
| D3 hero（可点击时） | `hero-pressed` | 遮罩加深 6% | 120ms |
| 主按钮 | `btn-pressed` | 背景加深 8%，`scale(.98)` | 120ms |
| 禁用态 | `none` | 透明度 60%，无按压反馈 | — |

实现约束：

- `hover-start-time="20"`、`hover-stay-time="70"`。
- 按压态只改变背景、透明度、缩放，不改变宽高、边距、字体，避免列表抖动。
- 按压反馈必须在 20ms 内出现；不得依赖长按。
- 不允许只在 hover 时展示关键信息。

### 6.2 响应式适配

| 断点 | 规则 |
| --- | --- |
| ≤ 320px（小屏） | rpx 自动缩放；标签字号不低于 18rpx；hero 标题最小 48rpx；卡片标题最多 2 行 |
| 375px（基准） | 按本文档 750rpx 设计稿 1:1 还原 |
| 390–430px（大屏） | rpx 自动放大；内容宽度仍为 686rpx；不额外增加信息 |
| ≥ 768px（平板/桌面） | 内容区最大宽度 750px 居中；页面底色铺满；hero 不拉伸到全屏宽 |
| 横屏 | hero 最小高度 360rpx；标题 48rpx；文案内边距 36rpx；底部固定栏加安全区 |

适配规则：

- 所有尺寸优先 rpx；`env(safe-area-inset-bottom)` 只用于底部固定栏。
- uni-app 的 rpx 默认最大适配宽度为 960px；超过 960px 时使用固定最大宽度，避免内容被无限放大。
- 图片统一 `mode="aspectFill"`；档案类图片需要完整展示时使用 `aspectFit`。
- 列表首屏图片立即加载；折叠区以下图片使用 `lazy-load`。
- 支持微信字体放大：标题、副标题允许换行，禁止固定高度裁切文字；大字号下卡片高度自适应。
- 深色模式暂不纳入 v1.0；如后续支持，颜色必须走 token，不在页面内写死。

### 6.3 可访问性

- 正文与背景对比度 ≥ 4.5:1；大字号标题 ≥ 3:1。
- hero 白色文字下方必须有遮罩，底部遮罩不透明度 ≥ 78%。
- 状态不能只用颜色表达，必须配文字标签。
- 卡片可点击区域高度 ≥ 88rpx（当前 176rpx 满足）。
- 图标按钮需提供 `aria-label`；纯装饰图使用空 alt。

## 7. 设计交付标准与格式

### 7.1 Figma 文件结构

| 页面 | 内容 |
| --- | --- |
| `00 Cover` | 封面、版本号、更新日期、负责人 |
| `01 Tokens` | 色彩、字体、圆角、间距、阴影样式 |
| `02 Components` | D2 卡片各状态、D3 hero 各状态、标签、按钮 |
| `03 Screens` | 云展馆页、章节页 750 × 1624 完整页面 |
| `04 Redlines` | 三个元素的标注图、间距、字号、颜色、裁切安全区 |
| `05 Assets` | 封面母版、导出切图、命名清单 |

画板与命名：

- 主画板：`750 × 1624`；小屏验证：`750 × 1334`；平板验证：`768 × 1024`。
- 组件命名：`SQ/CloudHall/Card/Default`、`SQ/CloudHall/Card/Pressed`、`SQ/CloudHall/Card/Highlight`、`SQ/Chapter/Hero/Default`、`SQ/Chapter/Hero/Fallback`、`SQ/Cover/Master`。
- 图层命名使用英文短横线，禁止 `Frame 123`、`矩形 5`。
- 所有组件使用 Auto Layout；间距、圆角、颜色、字体必须引用样式，不允许散落硬编码。

### 7.2 切图与资源交付

| 资源 | 格式 | 尺寸 | 体积 | 说明 |
| --- | --- | --- | --- | --- |
| 章节封面母版 | JPG / WebP | 1500 × 1000 | JPG ≤250KB；WebP ≤150KB | 同一张图服务卡片与 hero |
| 章节封面 @2x | JPG | 1000 × 667 | ≤150KB | 低倍屏兜底 |
| 章节封面 @3x | JPG | 1500 × 1000 | ≤250KB | 主交付 |
| 缺省封面 | CSS | — | — | 不切图，使用渐变 |
| 图标 | SVG + PNG @2x/@3x | 按 24×24pt 基准 | PNG ≤20KB | 线性图标，描边 1.5–2px |

命名规则：

```
chapter-cover-{chapterId}-{slug}@3x.jpg
chapter-cover-{chapterId}-{slug}@2x.jpg
```

示例：`chapter-cover-002-baigong@3x.jpg`

交付要求：

- 色彩配置 sRGB；照片不带透明通道；图标保留透明背景。
- 同一资源只保留一个母版，禁止多个画板重复导出近似图。
- 封面通过后台上传到媒体库，使用接口返回的 `/files/...` 地址；设计稿不直接引用本地路径。
- 交付包包含：Figma 链接、切图 ZIP、命名清单、更新说明。

### 7.3 标注与开发交接

标注图必须包含：

- 元素外框尺寸、内边距、间距、圆角、描边。
- 字体大小、字重、行高、字距、最大行数、省略规则。
- 色值与 token 名称（如 `$paper2`、`$red`），不只写十六进制。
- 图片裁切方式、安全区、焦点位置。
- 默认 / 按压 / 高亮 / 完成 / 加载 / 空 / 错误状态。
- 响应式断点与横屏规则。

组件契约：

| 元素 | 数据字段 | 状态 | 点击行为 |
| --- | --- | --- | --- |
| D2 卡片 | `id`、`title`、`summary`、`subtitle`、`coverUrl`、`chapterType`、`completed`、`lastReadTime` | 默认/按压/高亮/完成/读到此章/骨架 | 进入章节，携带 `lastNodeId` |
| D3 hero | `title`、`subtitle`、`summary`、`coverUrl`、`chapterType`、`sortOrder` | 默认/加载/缺省/可点击 | 默认不响应；如支持查看大图再增加 |

### 7.4 验收清单

- [ ] 750rpx 设计稿与实现 1:1 对齐，320/375/414/768 宽度无横向滚动。
- [ ] D1 封面在卡片与 hero 中主体完整，关键细节未被裁切。
- [ ] D2 卡片标题最多 2 行、副标题 1 行，长文案不撑破卡片。
- [ ] D3 hero 文案与封面之间有遮罩，白色文字对比度 ≥ 4.5:1。
- [ ] 按压态 20ms 内出现，且不引起布局位移。
- [ ] 高亮卡片全屏最多 1 个；完成/读到此章状态有文字标签。
- [ ] 无封面、图片失败、接口为空时均有缺省样式。
- [ ] 封面单张 ≤250KB，首屏加载无明显闪烁。
- [ ] 平板/横屏/大字号模式下无文字截断与遮挡。
- [ ] 所有颜色、字体、圆角均来自 token，无页面内新增近似色。

.hero-mask {
